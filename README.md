# FrozenLake Q-Learning — Topics in AI Assignment I

From-scratch tabular Q-learning on Gymnasium `FrozenLake-v1`, 8x8 slippery map. Uses Gymnasium for the environment only; learning algorithm is written in `agent.py`.

## Run

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python main.py
jupyter notebook experiment.ipynb
```

Full default run trains 5 agents (one final and four sensitivity settings), each for 30,000 episodes. It can take several minutes. For a quick smoke test, run `python main.py --episodes 500 --skip-sensitivity`; short runs generally will **not** learn a successful policy.

## Output

`outputs/q_table.npy`, `outputs/results.json`, `outputs/training.png`, `outputs/sensitivity.csv`, `outputs/sensitivity.png`, and `outputs/agent_demo.gif` are generated by `python main.py`. A successful GIF is recorded if the greedy policy reaches the goal in one of 30 attempts; `successful_gif_recorded` in results.json indicates whether this happened. Because the environment is stochastic, success cannot be guaranteed on every episode. If false, try longer training or another seed before submitting.
